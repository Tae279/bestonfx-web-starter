## Framer Notes

- Upload from `upload/` only.
- Use `nav-logo-light.webp` on the current Fizens light navbar.
- Use `nav-logo-dark.webp` only on dark hero/overlay sections.
- Do not upload the old `assets/logos/` dump as-is; it contains unrelated and heavy files.
- Keep logo sizing stable in Framer: set fixed height first, then let width auto-fit.
