# Architecture Decision Records

Use this folder for future ADRs.

Current architecture source of truth:

- `docs/architecture-decision.md`
- `docs/orchestration-plan.md`
- `docs/product-brief.md`

When adding an ADR:

- Use a short dated filename, for example `2026-05-26-agent-workflow.md`.
- Record context, decision, consequences, and verification notes.
- Do not add compliance-sensitive claims unless they are explicitly approved.
