# Issue Tracker

Default: GitHub Issues for `Tae279/bestonfx-web-starter`.

Skills such as `/to-prd` and `/to-issues` should publish PRDs and implementation slices to this repo's GitHub Issues when the `gh` CLI is authenticated.

If GitHub authentication is unavailable, stop and report the blocker instead of creating a second issue tracker convention.

Issue bodies should include:

- Product or technical objective
- Acceptance criteria
- Blockers and dependencies
- `AFK` or `HITL` ownership
- Compliance impact note
- Verification commands

Do not publish legal, regulatory, spread, leverage, commission, testimonial, or performance claims unless the source has been explicitly approved.
