# Triage Labels

Use these default labels for Matt Pocock-style agent skills:

- `needs-triage` - maintainer needs to evaluate
- `needs-info` - waiting on reporter
- `ready-for-agent` - fully specified and AFK-ready
- `ready-for-human` - needs human implementation or decision
- `wontfix` - will not be actioned

BestonFX-specific notes:

- Use `ready-for-human` for legal copy, regulatory wording, commission terms, testimonials, and trading advice.
- Use `ready-for-agent` only when the task has allowed files, acceptance criteria, and verification commands.
- Do not create duplicate label vocabularies unless the project owner explicitly changes this file.
