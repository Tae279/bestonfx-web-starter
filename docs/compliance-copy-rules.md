# Compliance Copy Rules

## Mandatory risk warning

```text
Forex/CFD และ Leverage มีความเสี่ยงสูง อาจทำให้สูญเสียเงินลงทุน โปรดศึกษาข้อมูลและความเสี่ยงก่อนตัดสินใจ
```

## Banned or high-risk wording

| Avoid | Safer replacement |
|---|---|
| กำไรแน่นอน | ผลลัพธ์ขึ้นกับตลาด กลยุทธ์ ต้นทุน และการบริหารความเสี่ยง |
| ไม่ขาดทุน | ไม่มีระบบใดสามารถป้องกันการขาดทุนได้ทั้งหมด |
| ไร้ความเสี่ยง | Forex/CFD และ Leverage มีความเสี่ยงสูง |
| สัญญาณแม่น 100% | ไอเดียการศึกษา/มุมมองตลาด ไม่ใช่คำแนะนำเฉพาะบุคคล |
| รายได้ IB แน่นอน | Commission ขึ้นกับเงื่อนไข program และ volume ที่เกิดขึ้นจริง |
| ดีที่สุด / อันดับ 1 | ใช้เฉพาะเมื่อมี source, date, region, award body |
| เหมาะกับทุกคน | ไม่เหมาะกับทุกคน ผู้ใช้ควรประเมินความเสี่ยงก่อนตัดสินใจ |
| เปลี่ยนชีวิต / รวยเร็ว | ใช้เครื่องมือและข้อมูลเพื่อการตัดสินใจที่มีวินัย |

## Required approval before publish

- Regulatory status
- License/entity wording
- Spreads
- Commission
- Leverage
- Account type conditions
- Payout examples
- DX Trade wording
- DX Exclusive wording
- Testimonials
- Awards/rankings
- Community size
- Performance figures

## Page-level placement

- Sticky risk bar: every public page
- Hero risk note: Home, Accounts, Markets, Partners, DX pages
- Footer: every public page
- Calculator outputs: before/after result
- Bot: every answer touching trading/account/product risk
