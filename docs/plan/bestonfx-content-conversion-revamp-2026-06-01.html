01 ปัญหาของ content ปัจจุบัน

ทำไมคุณถึงไม่ชอบ — วินิจฉัยตรงๆ จากไฟล์จริง

1. Copy “live” กั๊กจนหมดพลัง

ไฟล์ที่ใช้อยู่ (src/content/v2-home.ts) เต็มไปด้วย รอยืนยัน · Placeholder · Demo · Mock · POC ในคำที่ลูกค้าเห็น. ตัวอย่างจริง:

  • Tools เขียนว่า “Coming soon / Placeholder / Mock” — trader เห็นแล้วคิดว่าเว็บยังไม่เสร็จ
  • Accounts มี “DX Exclusive — แนวคิดบัญชีระดับสูงในระบบ DX” — คลุมเครือ ไม่มีจริง
  • IB section: “จำลองวิธีคิดรายได้พาร์ทเนอร์แบบไม่ใช่ข้อมูลจริง” — ภาษาเอกสารภายใน ไม่ใช่ภาษาขาย
Root cause: เอา compliance มาแก้ผิดที่ — ไปเขียนคำกั๊กให้ลูกค้าอ่าน แทนที่จะใช้ [verify] tag ภายในแล้วเขียนคำที่ มั่นใจแต่ซื่อสัตย์.

2. มี 2 ระบบ copy ขัดกันเอง

ของที่ดี (copy-deck-punchy.md — “เทรดบนความจริง”, honesty-contrast, $5/lot ชัด) ไม่เคยถูกใช้จริง. ของที่ใช้จริง (v2-home.ts) คือเวอร์ชันกั๊ก. แผนนี้ = เอา spine ที่ดีมาใช้จริง + ลับให้คม.

3. การนำเสนอแบน

เรียง section แบบ feature-dump ไม่มี narrative arc. ไม่มีจังหวะพา trader จาก “สงสัย → สนใจ → ไว้ใจ → ลงมือ”.

4. แผน hero อ่อน + เสี่ยง AI-slop

hero เดิมเป็น abstract + mock cards ลอยๆ. ขาด concept ที่สื่อ positioning. เสี่ยงหลุดเป็น “รูป AI generic” (gradient ม่วง-น้ำเงิน, stock trader ยิ้ม).

02 Target trader — เราคุยกับใคร

grounded จาก research ตลาด forex ไทย (FXEmpire, ForexBrokers, TradersUnion, WSA 2026)

เขาเป็นใคร

  • retail ไทย มือใหม่–ระดับกลาง อายุ ~22–45
  • เทรดผ่าน มือถือเป็นหลัก (finance traffic ~50% mobile, SE-Asia สูงกว่า)
  • ใช้ offshore broker เพราะไทยไม่มี broker forex ที่ legal จริง (XM/Exness/FBS ก็ offshore)
  • คุ้นศัพท์เทรดอังกฤษ (spread, leverage, lot) → English hook ไม่เป็นอุปสรรค

เขากลัว / อยากได้อะไร

  • กลัวสุด: โดนโกง / ถอนเงินไม่ได้ / สเปรดมีค่าซ่อน
  • อยากได้: ฝาก-ถอนผ่านธนาคารไทยไว, มีคนไทยช่วยจริง, ต้นทุนชัด, cashback/rebate
  • ตัดสินใจจาก: “ถอนได้จริงไหม” > “มีคนไทยช่วยไหม” > “ต้นทุนเท่าไร” > “เจ้านี้ของจริงหรือหลอก”
คู่แข่งหลัก = Exness — ครองตลาดไทยด้วย local-everything (ฝาก-ถอนแบงก์ไทยใน 1 นาที, ซัพพอร์ตไทย 24/7, ถอนเร็วแม้เสาร์-อาทิตย์). เราชนะ Exness ไม่ได้ด้วยการเลียนแบบ — ชนะด้วย ความชัด + ความจริง + ทีมไทยที่คุยได้จริงผ่าน LINE.

Choiceจิตวิทยา trader ไทยทำไมสนใจ + convert
Honesty-contrast “เราขายความจริง”ระแวงโบรกโกง + เบื่อทุกเจ้าตะโกน #1การยอมพูด “เราไม่อ้างอันดับ” = สะดุด + น่าเชื่อกว่า. trust ที่คู่แข่ง (ที่พึ่ง hype) ลอกไม่ได้ → ลดความระแวง = กล้าเปิด/ทัก

ตอบ objection (สิ่งที่ trader คิดในใจ)

เขาคิดเว็บตอบ
“ทุกโบรกพูดเหมือนกันหมด”เราไม่อ้าง #1 — ให้คุณเปิด MT ดูต้นทุนเอง + เปิดเงื่อนไข Rebate เต็ม
“จะโดนโกง / ถอนไม่ได้ไหม”ฝาก-ถอนผ่านธนาคารไทย + ทีมไทยช่วยจริง + เปิดเผย entity/กำกับดูแล
“ไม่ regulate โดยไทย”ไม่มีโบรกไหน regulate โดยไทย (XM/Exness ก็ offshore) — เราใช้มาตรฐานสากล FSCA/CySEC/MSB
“Rebate จริงไหม”เงื่อนไขเปิดเต็ม จ่ายทุกจันทร์ คิดจาก volume ไม่ใช่กำไร
“ทำไมไม่ใช้ Exness ไปเลย”ความชัดของต้นทุน + Rebate เป็น $/lot + ทีมไทยที่คุยได้จริงผ่าน LINE
“เทรดเสี่ยงไหม”เสี่ยง — เราบอกตรงๆ ก่อนคุณเริ่ม (= สัญญาณว่าเราจริงใจ)

Funnel logic (dual-CTA)

เปิดบัญชี = hard path (คนพร้อม) · LINE = soft path (คนลังเล = ส่วนใหญ่ของ trader ไทย).

LINE จับ soft-intent ที่ยังไม่ commit แล้วทีมไทย nurture → convert ทีหลัง. นี่คือ insight สำคัญ: ตลาดไทย = relationship-first, LINE = สะพาน trust ที่ form ปกติทำไม่ได้.

Hypotheses (วัดได้ ไม่ลอยๆ)

  • demo/register conversion 3–8% บน targeted traffic (industry health; <1% = โครงสร้างพัง)
  • LINE-click > register-click ในช่วงแรก (soft-intent สูง)
  • honesty hero → bounce ต่ำกว่า hype hero (A/B)
  • Calm Canvas (ไม่มีเลขปลอม) ไม่ลด trust เทียบ terminal (test)
  • mobile LCP <2.5s / CLS <0.1 = เงื่อนไขปล่อย
  • regulatory badge ใน hero → demo start +17% (industry benchmark)
benchmark ทั้งหมด = external industry (WSA/Unbounce/finxsol) ใช้เป็นเหตุผล “ทำไม pattern ได้ผล” — ไม่ใช่ตัวเลขของ beston และห้ามแสดงบนเว็บ.
