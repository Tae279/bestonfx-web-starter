# BestonFX Product Brief

## Context

BestonFX is a pre-launch Thai-market forex/CFD broker brand.

Positioning:

```text
Clean, blue-led fintech — premium, modern, trustworthy, Thai-first
```

Brand:

- Light royal blue / clean blue-led fintech aesthetic
- White, soft slate, light glass, subtle gradients
- Premium, modern, trustworthy — not black/gold private-bank styling
- Thai-first
- LINE-first support/conversion (LINE green only on LINE CTA)
- See `DESIGN.md` + `docs/brand/tokens.json` for the brand system

## Public site objectives

1. Build trust before conversion.
2. Explain risk clearly.
3. Surface account types, markets, tools, support, education, and IB program.
4. Capture leads through LINE and forms.
5. Prepare for AI customer-service bot and IB portal.
6. Avoid dependence on existing CRM and trading portal in MVP.

## Exclusions

- Existing CRM
- Existing user trading portal
- Payment processing
- Live KYC
- Live trading data
- Live commission calculation

## Primary audiences

- Thai retail traders
- Beginner/intermediate traders from LINE/Discord/TikTok/YouTube
- IB partners on lot-based commission model
- DX ecosystem users: DX Academy, DX Trade, DX Exclusive

## MVP pages

- Home
- Why BestonFX
- Accounts
- Markets
- Tools
- Partners
- Support
- Risk Disclosure
- Admin placeholder
- Partner dashboard placeholder

## Compliance stance

Sell:

- Transparency
- Risk education
- Tools
- Thai support
- DX ecosystem
- Professional process

Do not sell:

- Profit guarantee
- Win rate
- Risk-free trading
- Lifestyle fantasy
- Guaranteed IB income
