หลัก Motion ที่ทำให้ดูแพง

เว็บที่ดูแพงไม่ได้ขยับเยอะกว่า แต่ขยับเป็นระบบกว่า.

กฎหลัก

1. หนึ่ง scroll ต้องเล่าหนึ่งเรื่อง

แต่ละช่วง scroll ต้องตอบว่า user ได้รู้อะไรเพิ่ม ไม่ใช่แค่เห็นของลอย. สำหรับ BestonFX ให้ผูกกับ trust, platform, risk, support, market education.

2. ความลึกสำคัญกว่าของตกแต่ง

ใช้ parallax เฉพาะ layer ที่มีบทบาท: background atmosphere, mid product UI, foreground decision/trust card.

3. Motion ต้องไม่แย่งการควบคุมจาก user

ห้าม scroll-jacking. ให้ scroll ปกติ แต่ map progress ไปที่ transform/opacity/scale เหมือน Framer Scroll Transform หรือ GSAP scrub.

4. Motion พรีเมียมต้องมีน้ำหนัก

ใช้ custom easing, stagger และ spring-like weight. หลีกเลี่ยง linear/ease-in-out default เพราะทำให้เว็บดูเหมือน template.

5. Performance คือส่วนหนึ่งของความหรู

ขยับ transform และ opacity เป็นหลัก. เลี่ยง animation ที่กระทบ layout/paint, continuous blur ตอน scroll และ 3D หนักบนมือถือ.

6. ต้องมี reduced motion

เมื่อ user เปิดลด motion ต้องปิด parallax, cursor tilt, glow loop และ scroll-scrubbed motion เหลือแค่ fade สั้น ๆ.

Spline Pro ใช้ยังไงให้คุ้ม

ใช้ Spline เป็น signature scene ไม่ใช่ใส่ทุก section. จุดที่คุ้มสุดคือ hero เพราะช่วยให้เว็บดู futuristic ทันที แต่ต้องมี poster fallback และ mobile fallback เสมอ.

Spline Pro

ควรดึงจาก Community ไหม?

ใช้ได้ แต่ไม่ควรแปะตรง ๆ. ให้ใช้ Community/Library เพื่อหาโครง scene, material, object หรือ lighting idea แล้ว remix ให้เป็น BestonFX เอง. สำหรับ production ให้ชอบ Spline Library หรือ scene ที่ชัดเจนว่า remix/use ได้ และเปลี่ยน brand/material/camera ทั้งหมด.

ควรสร้างใหม่ตรงไหน?

Hero scene ควรสร้างใหม่. เพราะเป็น first impression ของ broker. สร้าง trading command center แบบ abstract, ไม่มีตัวเลขจริง, ไม่มี license text, ไม่มีกราฟที่เหมือน signal.

ใช้ Pro setting อะไร

ปิด Spline logo, ใช้ transparent background ถ้าจะ blend กับ Framer, ตั้ง mouse events เป็น local/container, ปิด zoom/pan บน touch, ใช้ lazy loading และใส่ poster image ระหว่างโหลด.

ค้นหาอะไรใน Spline

ลองค้น/ดูหมวด: `Glass`, `Environment`, `Interactivity`, `3D Mockups`, `Product Design`, `Dashboard`, `Abstract UI`, `Particles`. เอาเฉพาะ object/material/lighting ไม่เอา scene สำเร็จทั้งก้อน.

แผนทำใน Framer แบบลงมือได้

ทำด้วย Framer ก่อน เพราะ POC ตอนนี้อยู่บน Fizens template. Custom code เป็น fallback เฉพาะจุดที่ native effects ไม่พอ.

Framer first
สร้าง `HomeHeroImmersiveStage`
Parent section height `180vh-220vh`, visual wrapper sticky `top:0`, height `100vh`, overflow hidden. นี่คือฉากหลักที่ทำให้คนร้อง wow.
จัด 3-layer composition
Background: glow/trading-room still. Mid: Spline dashboard/device. Foreground: Framer trust/risk/LINE cards. ให้ copy อยู่ใน Framer เพื่อแก้ compliance ง่าย.
ตั้ง Scroll Transform ด้วย Section in View
ทุก layer ผูกกับ scroll section เดียวกันเพื่อให้ timing พร้อมกัน. หลีกเลี่ยง page-wide "on scroll" สำหรับ hero เพราะควบคุมจังหวะยาก.
ตั้งค่า hero reveal
Device initial: opacity 0, y 48, scale .92, rotateX 8deg, blur 10. End: opacity 1, y 0, scale 1, rotateX 0, blur 0. Duration .9s, easing cubic-bezier(.16,1,.3,1).
ตั้งค่า parallax ratios
Background y -6% to 6%, mid y -12% to 12%, foreground y -20% to 20%, opacity .75 to 1 to .75, scale .98 to 1.02. Mobile ลดครึ่งหนึ่ง.
ทำ scene cut หลัง hero
จาก dark cinematic hero ตัดเข้า clean/light trust หรือ account section. ใช้ contrast เป็น wow ไม่ต้องเพิ่มเอฟเฟกต์ซับซ้อน.
ทำ microinteractions
Primary CTA hover: scale 1 to 1.025, arrow/island shift 2-4px, duration .22-.32s. Secondary LINE CTA ต้องนิ่ง อ่านง่าย และไม่ดูเป็นปุ่มรองที่ถูกซ่อน.
ทำ mobile fallback
เปลี่ยน sticky stage เป็น static poster + fade-rise. ปิด cursor depth, ลด parallax 50-70%, และอย่า autoplay Spline หนัก ๆ บนมือถือ.
