# Thai SEC Forex Promotion Compliance

## Current Project Status

This skill is deprecated for the current BestonFX Framer POC. The latest founder direction is:

- Thai SEC is not the controlling frame for this Forex/CFD broker website.
- Focus on international regulator/entity proof and Thai-market broker behavior.
- Use `docs/skills/international-forex-broker-market-compliance/SKILL.md` instead.

## Core Rule

Treat Forex/CFD copy as high-risk financial promotion. Do not publish claims unless the fact is approved and source-backed.

## Mandatory Warning

Use this warning on every claim-bearing page, hero, account table, market page, partner page, calculator, AI bot surface, and footer:

```text
Forex/CFD และ Leverage มีความเสี่ยงสูง อาจทำให้สูญเสียเงินลงทุน โปรดศึกษาข้อมูลและความเสี่ยงก่อนตัดสินใจ
```

## Banned Copy

- Guaranteed profit or income
- Risk-free, low-risk, or no-loss language
- Guaranteed IB commission or partner earnings
- Guaranteed signal accuracy or win-rate claims
- Best / number one / top-ranking claims without source, date, geography, and approval
- Fake testimonials, fake review scores, fake trader counts, fake country counts
- Regulatory/license claims not approved by legal/compliance

## Safe Pattern

Use:

- transparency
- risk education
- process
- support
- verified platform/tool availability
- placeholders for unconfirmed claims

Placeholder:

```text
รอยืนยันข้อมูลจากฝ่ายกำกับดูแลก่อนเผยแพร่
```

## Review Workflow

1. Identify every claim: regulation, account terms, spread, leverage, commission, payout, support SLA, platform, tool, DX Trade, DX Academy, DX Exclusive, IB.
2. Mark each claim as `approved`, `needs source`, or `remove`.
3. Replace unapproved facts with the standard placeholder.
4. Add the mandatory risk warning near the claim, not only in the footer.
5. Remove any copy that frames trading as wealth growth, financial freedom, easy money, or guaranteed outcomes.
